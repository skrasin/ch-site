# h — сайт кабинета медленного искусства

Сайт кабинета медленного искусства. Убежище для светского уединения: одна комната, одно произведение, один час.

Две страницы, ни сборки, ни зависимостей: чистые HTML, CSS и один файл на
ванильном JavaScript. Открывается как есть — хоть с диска, хоть с любого
статического хостинга.

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Главная: чертёж фасада и бронь — комната, дата, час |
| `rules.html` | Правила посещения |

## Структура

```
index.html            главная
styles.css            стили главной
site.js               тема и строка брони
rules.html            правила посещения
rules.css             стили правил
favicon.svg           знак, светлеет в тёмном интерфейсе
brand/                фирменный стиль, подключается как есть
  tokens.css          цвет, типографика, геометрия знака, тёмная тема
  facade-2x1.png      чертёж фасада, кадр 2:1, линии прозрачные
  facade-source.jpg   исходный чертёж
  mark-*.svg          знак: горизонтальный, вертикальный, в инверсии
rules.txt / rules.md  исходный текст правил
```

## Как устроено

**Дизайн-система.** `brand/tokens.css` подключается обеими страницами как есть,
значения не переопределяются. Цвет, кегли, геометрия знака, тёмная тема — всё
приходит оттуда. Полная документация системы:
<https://skrasin.github.io/gallery-ch/>

**Тема.** Страницы следуют настройке системы через `prefers-color-scheme`.
Тумблер на главной перекидывает свет на время сеанса и ничего не запоминает:
после перезагрузки страница снова идёт за системой.

**Двери на чертеже.** Чертёж — линейная графика на прозрачном фоне, поэтому
охра подкладывается **под** него: цвет проступает в проёме, линии остаются
сверху. Зоны заданы в процентах от кадра 1800 × 900 и держатся при любом
размере экрана. Комната 1 — левая дверь, Комната 3 — правая; выбор в списке и клик по
двери — одно и то же состояние.

**Кадр.** Ширина чертежа считается от высоты окна, чтобы главная умещалась в
один экран без прокрутки. Нижняя граница — 600 px: на низком окне появляется
короткая прокрутка, но чертёж не мельчает.

**Движение.** Единственный переход — проявление и растворение, 600 мс, линейно.
Ни сдвигов, ни масштабирования. `prefers-reduced-motion` уважается.

## Локально

```bash
python3 -m http.server 4173
```

Затем открыть <http://localhost:4173>. Файлы можно открыть и напрямую
(`file://`) — всё работает, кроме относительных путей в некоторых браузерах.

## Публикация на GitHub Pages

Сайт статический, сборка не нужна. В настройках репозитория:
**Settings → Pages → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.

Все пути относительные, поэтому сайт одинаково работает и в корне домена, и в
подпапке вида `username.github.io/ch-site/`.

## Что осталось заполнить

В тексте правил стоят метки-заглушки — до публикации их нужно заменить:

- `[24 часа]` — срок бесплатной отмены
- `[дата]` — дата вступления правил в силу

Кнопка «ЗАБРОНИРОВАТЬ» пока без действия: значения полей живут только в
разметке, отправки брони нет.
